# Collection Tab Images – Size & Format Notes

## Purpose

These images are used for the small category tabs on the Collections page.

Examples:
- All
- Pattu
- Cotton
- Silk
- Designer
- Wedding
- Daily

The images are shown inside `.collection-tab__media`.

## Recommended Image Size

Best size:

```txt
400 × 448 px

ratio : 1 : 1.12

webp format
